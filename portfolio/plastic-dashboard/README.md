# 🌍 Global Plastic Waste Data Dashboard

An interactive data visualisation platform designed to highlight the scale of single-use plastic production and its environmental impact. Built with a sleek "Slate & Sky" aesthetic, this dashboard provides real-time estimates and historical data analysis.


## 🚀 Features
* **Live 2026 Waste Ticker:** A real-time counter estimating plastic waste production based on current annual growth rates.
* **Interactive Visualisations:** Dynamic Line and Bar charts powered by **Chart.js**, featuring custom tooltips and responsive axis scaling.
* **Mindful Shopping Insights:** Interactive "flipping cards" provide actionable alternatives to common single-use plastics.
* **Latest Reports Slider:** A curated news feed for the latest developments in global sustainability and policy.
* **Direct Action Integration:** Integrated tools for users to calculate their footprint and donate to ocean cleanup initiatives.

## 🛠️ Tech Stack
* **HTML5 & CSS3:** Custom-built glassmorphism UI with a responsive mobile-first grid.
* **JavaScript (ES6):** Core logic for data fetching, the live ticker, and news slider.
* **Chart.js:** Data visualisation library for high-performance rendering.
* **JSON:** Local data structure for historical waste trends and contributor stats.

## 📊 Data Source
Data is synthesised from reports provided by the **OECD Global Plastics Outlook** and **UNEP 2026** environmental studies.

## 🔧 Installation & Usage
No installation is required. Simply clone the repository and open the local file in your browser:
1. Clone the repo: `git clone https://github.com/your-username/plastic-waste-dashboard.git`
2. Open `plastic-dashboard.html` in any modern web browser.
